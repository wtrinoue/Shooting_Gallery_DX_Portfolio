最終更新: 2026-10-13 (モードの切り替わり方・ハッチ・PCのキー) / 初版 2026-10-11 前セッションの Claude Code が作成。
この文書だけ読めば「何を作ったか・どう作られているか・ユーザーの好み・注意点」が分かるように書いてある。

## 0. まず守ること (ユーザーの好み・決まりごと)

- **返答は必ず日本語。** (ユーザーから明示的に依頼あり。メモリにも保存済み)
- ユーザーは Unity / VR 初心者寄り。専門用語は短く補足し、手順は「どこを押すか」まで書くと喜ばれる。
- **BuildScene (GalleryBuilder) は本番では使わない。** エディターで「シーンに生成」/「作り直す」ボタンを押して `ShootingGallery` という子オブジェクトを作り、それをシーンにコピペして使う運用。
  - そのため **生成物は、ビルダー無しで再生しても完全に動く** 必要がある (参照はすべてシリアライズ、マテリアルは .mat に保存)。
  - **新しいオブジェクト/構造を追加したら「作り直す → 貼り直し」が必要** と毎回伝える。スクリプトの中身だけの変更なら不要と伝える。
- **Inspector に保存済みの値はコードの初期値より優先される。** 初期値を変えて確実に反映させたい時は、フィールド名を変える手を使ってきた (例: `weaponSeconds`, `sniperGap`)。
- 1ファイル1 MonoBehaviour (シーン保存のため)。
- 操作は **右手トリガーだけ**。プレイヤーは中心固定で見回すだけ。VR が無い時はマウスで操作できる (右ドラッグ=視点、左クリック/Space=発射)。
- 音はすべて **コードで波形生成** (外部素材なし)。差し替え用の AudioClip スロットはある。

## 3. ゲーム仕様 (現在の実装)

### 基本
- START の的を撃つと開始。1ラウンド **90秒**。終了後スコア表示 → 4秒でタイトルに戻る。ハイスコアは PlayerPrefs。
- 点数の種類は **10 / 50 / 100 / 200 / 300 / 500**。点数で色と大きさが変わる (`PointStyle.cs`: 高いほど小さく派手。300以上は光る)。
- **点数の配分: メイン屋台は低め、フィーバー屋台は高め** (2026-10-12 にユーザーの希望で変更。動き・並びは以前のまま、数値だけ変えた)。
  値は `GalleryBuilder.cs` の各 `BuildXxx` に直接書いてある (変えたら「作り直す」が必要)。

| 屋台 | 点数 |
|---|---|
| メイン (ひな壇) | 下段 10×5 / 中段 10,50,(左右に動く100),50,10 / 上段 50,100,赤い玉,100,50 (最上部レールの 200 は削除済み) |
| Conveyor | 下 100,200,100,300,100,200 / 上 200,300,200,500,300,500 |
| FerrisWheel | 200,300,500,200,500,300 |
| PopUp (3段×4穴) | 100,200,100,200 / 200,300,200,300 / 300,500,500,300 |
| Pendulum | 200,300,500,300,200 |
| Carousel | 下 100,200,300,200,100,500,200,300 / 上 300,500,300,500,300 |
| Elevator | 200,300,500,300,200 |
| DuckParade | 下 100,200,100,300,100,200,100 / 上 200,500,300,500,200,300 |
| Roulette | 周り 200,300,500,200,500,300 + 中央 500 |
| Turnstile (表/裏) | 100/300, 200/500, 300/500, 200/500 |

- 特殊な的の点数 (武器の的 100、爆弾の的 50、青い玉 300、UFO 1000、スナイパー 500〜3000、ドレミ 100〜800) はこの配分とは別で、変えていない。

### 特殊な的 (WeaponDropper が普通の的を化けさせる)
化けるのは **起き上がる瞬間** (`Target.Rising`)。だから屋台ごとの動き (コンベアー・観覧車など) にそのまま従う。
| 的 | 効果 | 備考 |
|---|---|---|
| MG / SG / BOMB | 武器が **3秒** 変わる (銃の上にゲージ) | 出やすさ MG 6 : SG 3 : BOMB 1 |
| 爆弾の的 (黒い爆弾) | 当てると少し後に爆発し周りの的を倒す。連鎖あり | 50点 |
| 赤い玉 (メイン屋台の最上段) | **フィーバー開始** | 300点 |
| 青い玉 | フィーバー中・メイン以外の屋台に1回だけ。撃つと **ボーナスステージ** | 300点 |
| スナイパーの的 (黒板に赤い照準) | **スナイパーチャレンジ** 開始 | 同時に1つまで |
| マシンガンチャレンジの的 (紺の板に金の小さな的、MG CHALLENGE) | **マシンガンチャレンジ** 開始 | チャレンジの的はスナイパーと合わせて同時に1つまで |

### 武器
ハンドガン (基本) / マシンガン (連射) / ショットガン (14粒, 12°) / 爆弾ランチャー / スナイパーライフル (チャレンジ専用・1発)。
ヒットスキャンは **エイム補正** あり: 細い線で外れたら半径 0.12m の太い線で拾う (ショットガンは半分、スナイパーは補正なし)。壁の向こうの的は拾わない。

### フィーバー (20秒)
- 赤い玉で開始。まわりに屋台がせり上がり 360 度、左手の銃も右トリガーで同時に撃てる (二丁拳銃)。
- フィーバー屋台は **9種類のギミック** (Conveyor, FerrisWheel, PopUp, Pendulum, Carousel, Elevator, DuckParade, Roulette, Turnstile) から毎回ランダムに選び、ランダムな順で並べる。

### ステージ (時間で屋台の輪が広がる)
- `stageStallCounts = {6,7,8}` (メイン含む輪の軒数), `stageInterval = 30秒`。HUD に `STAGE n`。
- 輪の半径は屋台の間隔 (弦) を保つよう自動計算: 6軒 3.5m → 7軒 約4.0m → 8軒 約4.6m。
- **フィーバー外はメイン屋台は最初の位置のまま。** フィーバー中は輪の半径まで後ろに下がり、終わると戻る。
- フィーバー中に拡張が来たら、出ている屋台が地上のまま後ろへ滑り、足りない分が新しくせり上がる。
- 拡張時はグレードアップ音 (`stageup`) とメッセージ。
- スナイパーチャレンジ中は拡張を待たせる (終わった直後に拡張)。

### ボーナスステージ (青い玉)
- プレイヤーの **足元の床が左右にスライドして開き**、地下室 (深さ 5m) が見える。プレイヤーは空中に立っている感じ。
- 底に上向きの大きな的。当てるたび **ド→ドの音階** が上がり、点数は **100, 200, … 800**。8回で完成音 → 床が閉まる。
- (最初は「観音開きの扉から的が出てくる」版を作ったが、ユーザーの意図と違ったので作り直した経緯あり)

### UFO
- ときどき頭上を一直線に横切る (高さ 6.5m)。**1000点**。飛行中はうなり音 (立体音響)。

### スナイパーチャレンジ (最新の機能)
1. スナイパーの的が出る。**出す屋台を先にランダムに決める**: フィーバー外はメイン屋台、フィーバー中はメイン以外の屋台。立っている的を1つ倒して 0.4秒後に起こし、その時に化けさせる。
   - 間隔: フィーバー外 6〜12秒 / フィーバー中 3〜6秒 (前の的・チャレンジが終わってから数える)。開始 4〜7秒後に最初。フィーバー開始時は 1.5〜3秒後に出す。放置 5秒で引っ込む。
   - 拡張が近い (約6秒以内)・ラウンド残りが足りない時は出さない (`GameManager.CanOfferSniper`)。
2. 撃つと **その屋台が地下に引っ込み**、屋台があった方向の遠く (22m, 高さ 3.5m) に大きな的が浮かんで現れる。霧が遠ざかる。
3. 銃が **スナイパーライフル** (レーザーポインター付き, 1発のみ, 二丁拳銃は一時停止) に。制限時間 10秒 (ゲージ)。チャレンジ中はフィーバーの残り時間が止まる。
4. 当たれば **真ん中ほど高い点** (縞模様の輪: 外側から 500 / 1000 / 2000 / 3000。半径と点数は SniperChallenge の ringRadii / ringPoints) + ファンファーレ。外す/時間切れなら残念音。どちらでも屋台が復活し、的は消える。

### マシンガンチャレンジ (2026-10-12 追加)
1. 出し方はスナイパーの的と同じ (WeaponDropper が先に屋台を選ぶ。フィーバー外はメイン、フィーバー中はメイン以外)。間隔: フィーバー外 10〜16秒 / フィーバー中 5〜9秒、開始 12〜18秒後に最初。スナイパーと続けて出る時は最低 3〜5秒あける。予約の枠はスナイパーと共有 (`UpdateChallengeReservation`)。
2. 撃つと **その屋台と両隣の屋台が引っ込む** (輪の順 = メイン → activeFeverStalls)。フィーバー外はメインだけ引っ込む。
3. 引っ込むのと **同時に**、同じ方向 (撃った屋台の位置) に **横長の屋台 (普通の1.8倍の幅、看板 MACHINE GUN CHALLENGE)** がせり上がる。3段の棚に **カップがすき間なく26個ずつ (計78個、全部100点)** (間隔 0.17m。棚はカップの幅に合わせる)。せり上がり終わるとカップが左から順に現れ、HUD に `MG 当てた数/78`。
4. せり上がり終わった時にマシンガンを **8.6秒** (現れる0.6秒 + 8秒) 渡す。**全部落とすか、マシンガンの時間切れで終了** → 0.3秒後に横長の屋台が (残ったカップごと) 沈み、同時に元の屋台が戻る。ハンドガンに戻る。全部落とすとファンファーレ。
   - カップは撃たれると倒れずに **棚の後ろへ弾き飛ばされ、回りながら床まで落ちる** (`Target.knockOffOnHit`。見た目 (visual) だけを動かす簡易な放物線。奥の壁は knockMaxBack で突き抜けない)。
   - カップに当たると **空き缶を倒した音** (`Sfx.Play("can")`。カーン + カラン、高さ違い3種類からランダム。`Sfx.canHits` に差し替え可)。
   - **毎回ランダムな3個のカップが爆弾に変わる** (MachineGunChallenge.bombLooks の数。カップの見た目は Target.face にまとめてあり、爆弾の時はそれを隠して爆弾の見た目を付ける)。爆弾を撃つと0.12秒後に半径0.6m (`bombRadius`) で爆発し、周りのカップを落とす (近くの爆弾も誘爆)。爆弾も数に入る。
   - 横長の屋台は `Stall` だが targets は空 (沈む時にカップを消さないため)。カップは MachineGunChallenge.targets が持つ。
6. **スナイパーもマシンガンも1ラウンドに必ず1回は出る**: まだ出ていない方は、ラウンド残り55秒 (`WeaponDropper.guaranteeByTimeLeft`) になったら、前のチャレンジから3〜5秒あけてすぐ出す。両方の時間が来ていたら、まだ出ていない方を優先。「出た」= 的が化けた時点 (撃たなくても1回と数える)。

### 音の制限 (Sfx.PlayLimited)
- 同じ種類が 0.07秒以内に重なったら鳴らさない (複数同時に倒した時など)。0.4秒以内に続くと音量を下げていく (下限 35%)。
- 銃声は重複だけ防ぎ音量は下げない。

## 4. 生成物 (`ShootingGallery`) の構造メモ
- `GalleryBuilder.WorldName = "ShootingGallery"`。シーンに既に GameManager があればビルダーは何もしない。
- **生成直後は基本の屋台だけ見える**。フィーバー屋台 9軒・遠くの大きな的・UFO は非表示で置かれる (最新の変更)。
- 地面は足元に 3m 四方の穴 (`PitHalf=1.5`) が空いた4枚の床。穴は床扉でふさがっている。
- 屋根と看板は当たり判定なし (UFO を狙う弾をさえぎらないため)。
- 平たい円柱の CapsuleCollider は球になってしまうので、`Prim()` で凸 MeshCollider に置き換えている。
- 以前あった「遠くの提灯の列 (Lanterns, 半径9m)」はユーザーの希望で削除済み (屋台の屋根の小さな提灯は残っている)。

## 5. 過去にあった問題と対処 (同じ失敗をしないために)
| 症状 | 原因 / 対処 |
|---|---|
| 全部ピンク | 再生中のオブジェクトをコピーしていた → 編集中に「シーンに生成」ボタンを使うよう案内。SceneEnvironment が警告を出す |
| 回転台の下の段の的が当たらない | 平たい円柱のカプセルが球になる → 凸 MeshCollider |
| UFO が真上でしか当たらない | 屋根・看板の当たり判定を外し、UFO の判定を大きく、航路を頭上横切りに |
| 武器時間を変えても反映されない | Inspector の保存値が優先 → フィールド名を変えた |
| 入れ子コルーチンが止まらない | Target を Update 駆動の状態機械に書き直し |
| CS0102 `Disguise` 重複 | メソッド名を `ApplyDisguise` に |
| スナイパーの的がメイン屋台にばかり出る | 起き上がった的に化ける方式だったため撃っている屋台に偏った → 先に屋台をランダムに選ぶ方式へ |

## 6. 会話の流れ (ユーザーの依頼の時系列)
1. develop.txt の内容で VR 射的を構築 (右トリガーのみ)。
2. 空オブジェクトにアタッチするビルダー → 後にエディターボタンで生成しコピペする方式へ。
3. VR 設定の相談 (OpenXR, Project Validation, Quest 1/2/3 対応)。
4. 屋台ギミック化・点数設定・爆弾武器・ショットガン拡大。
5. 武器時間短縮 (5秒 → 3秒) とゲージ表示、準備中の仮表示。
6. 回転台の当たり判定修正、武器の的を全屋台にランダム出現、UFO 追加。
7. コピペ運用の徹底、ピンク問題、UFO の航路修正。
8. 爆弾の的、フィーバーのギミック追加 (9種からランダム5軒)。
9. 青い玉 → ボーナスステージ (足元スライド式に作り直し)。
10. Quest で遊ぶ方法の PDF (方法A・B)。
11. ステージ制 (時間で 6→7→8 軒、メインはフィーバー時だけ後退)。
12. 当たり判定を広く (エイム補正)。
13. 同時撃破の音を抑える、拡張時のグレードアップ音。
14. スナイパーチャレンジ追加 → どの屋台にも出るよう修正 → 頻度アップ。
15. 「日本語で会話して」→ 以後日本語。
16. 周りの提灯の列を削除。
17. 作り直し直後は基本の屋台だけ見えるように。
18. この引き継ぎメモを作成。
19. (2026-10-12) 点数の配分変更: メイン屋台は低い点数 (10〜200)、フィーバー屋台は高い点数 (100〜500) に。挙動はそのまま。
20. (2026-10-12) マシンガンチャレンジ追加 (撃った屋台と両隣が引っ込み、24個の100点の的をマシンガンで撃つ)。
    → 同日、浮かぶ的から「横長の屋台の棚に並んだカップ (撃つと後ろへ落ちる)」に変更。
    → 同日、屋台の入れ替えを同時に、カップの間隔を詰め (0.56→0.4m)、当たった音を空き缶の音に。
    → 同日、カップをすき間なく78個に、毎回ランダムに3個が爆弾に。
    → 同日、スナイパーとマシンガンのチャレンジが1ラウンドに必ず1回は出るように。

- **カジノ**: ふたが閉まったら ScreenFader (目の前の黒い板) で視界を完全にふさぎ、スポットライトの音だけ聞かせ、全部の明かりが点く瞬間に一気に開ける。終わりはまた黒い板でふさぎ、その間に地味な壁・天井・床だけ＋夜の明るさに戻し、しばらくして開けてから天井が外れて壁がしまわれる (CasinoHall の blackoutTime / outroDarkHold など)。
- **西部劇**: 黒い暗転をやめて **砂嵐** に (ScreenFader を砂の色で覆う＋砂粒が横殴りに飛ぶ＋風の音 `Sfx "sandstorm"`)。帰りは砂嵐で見えない間に屋台と的をその場に並べる (`Stall.ShowImmediate`、GameManager.OnWesternLeft)。ScreenFader.FadeTo は色を渡せるようになった。
- **宇宙**: 床が透けるのを 1.2秒 (`groundFadeTime`) に速め、空の暗さも1秒で。透ける床が紫っぽく見えないよう、色も黒へ近づけ、つや・映り込みを切る。
- **怪獣など全モード共通**: モードが終わって屋台が戻りきるまで、屋台の拡張・フィーバー / DX の残り時間を止める (`StallsBusy` / `HoldStallsFor`)。戻る途中に別の屋台がひょっこりせり上がっていたのはこれが原因 (チャレンジ中に待たせていた拡張が、終わった瞬間に始まっていた)。
- **ハッチ**: 半径 1.95m → **3.3m** (`PitRadius`。屋台6軒の輪の、屋台の奥行きの半分くらいまで重なる)。輪が広がってもハッチは広がらない。地下室の的は輪12個×2段＋底に増やし、開くたびに **1000 / 2000 / 3000 点をランダム** に割り当てて的に書く (BonusStage.pointChoices / pointLabels)。8回当てるまでなのは同じ。 → 同日、的は撃っても壊れない (stayUpOnHit。縮んで戻る) ように変更。当てるたびにその的の点数が 500 ずつ下がり、500 で止まる (pointDrop / minPoints)。 → 点数が下がらないバグを修正: GameManager が target.points に「入った点数」を書き戻していたので、BonusStage は的ごとの今の点数を自分の配列 (currentPoints) で覚えるようにした。
- **PC のキー**: 1 = デバッグ、2 = エンドレス、3 = リセット (VR のボタンと同じく長押し。テンキーも可)。前は X / E / R だった。 視点は右ドラッグに加えて WASD でも回せる (A/D 左右、W/S 上下。`keyLookSpeed` = 90度/秒)。
- **UFO**: いつものプレイ中 (フィーバー中も含む) だけ飛ぶ (`GameManager.IsNormalPlay`)。チャレンジ・別の世界のモード・そこから戻る途中・DX・ボーナスステージが始まったら、飛んでいる UFO はその場で消してうなり音も止め、待ち時間も止める。
- **モードの的を撃ったらすぐ始める** (Core/GameManager.ModeQueue.cs): 前は、他のチャレンジ・モード・DX・ボーナスステージの途中で撃ったモードの的は何も起きずに消えていた (マシンガンなどモード中の武器で撃つと反応しないように見えた)。今は撃ったらすぐ発動: 途中のものを全部終わらせ (`EndAllForNewMode`。デバッグモードの DebugClearFor も同じものを使う)、片付けが済みしだい始める。**同時に撃った時 (0.3秒以内 `simultaneousModeWindow`) は、いちばん先に当たったモードだけ。2番目以降は取り消す**。順番待ちで遅らせるのではない (ユーザーの指定)。StartSniper / StartMachineGunChallenge は屋台を受け取る形。
- **別の世界のモードの的の出方** (WeaponDropper): **5秒の区切りごとに 0〜5秒のランダムな時刻を抽選し、その時刻に3か所同時に出す** (`stageBatchWindow` / `stageBatchCount`。同時に出ていてよいのは `stageMaxOutTotal` = 6 まで。モード中は時計が止まる)。1回の3つは別の種類 (7種類の袋から)、なるべく別の屋台の的。経緯: 30秒ごとに9つ → 10秒ごとに1つ → 今の形。それ以外の特殊な的 (武器・爆弾・青い玉・DX・チャレンジ) は今まで通り。 化けるのは、予定の時刻に「今出ている屋台全部の立っている普通の的」からランダムに選んだもの (いったん倒して起き上がる時に化ける。UpdateStageReservation)。前は時刻のあと最初に起き上がった的だったので、起き上がりの早いメイン屋台に偏っていた。
- **チャレンジは屋台の「場所」を引っ込める** (GameManager.Challenges.cs の SameSpot / IsChallengeSpot / CurrentStallAt): 豪華タイムの入れ替えで同じ場所に豪華版 ⇔ 普通版が入っても、チャレンジ中はその場所にどちらも出さない。終わったら、その場所の今の版を戻す。スナイパー / マシンガンのチャレンジの的を撃っても DX は終わらせない (EndAllForNewMode(keepDeluxe))。DX の終わりとスナイパーが重なって、屋台が出てきて的を撃てなかった不具合の対策。
- **負荷の改善 (2026-10-13)**: (1) ビルダーの Prim() は、いちばん長い辺が 0.8m 未満・光る・半透明の部品は影を落とさない (文字・地面も)。(2) 使い捨ての見た目は Common/FxPool.cs で使い回す (点数の文字・爆発・弾の軌跡・爆弾・ミサイルと煙の筋・手裏剣 / ダーツ・宇宙の破片・西部劇の砂粒と汽車の煙・カジノの紙吹雪)。新しく使い捨ての物を作る時も FxPool.Get / Release を使うこと。(3) HUD は表示する数字が変わった時だけ書き換える (HudSignature)。銃の上の文字・ゲージの色も変わった時だけ。(4) エイム補正は SphereCastNonAlloc、爆発は OverlapSphereNonAlloc (入れ子の爆発の時だけ配列を作る)。WeaponDropper の候補リストは使い回し。(5) 的 (Target) は、することがない時は enabled = false で眠り、動きが必要になった時に Wake で起きる。(6) 効果音は短い物だけ起動時に作り、長い物は GenerateLongClips で1フレーム4ms ずつ作る。メッシュの結合はユーザーの指示でしていない。
- **別の世界へ飛ぶ的が最初の屋台に出すぎる問題** (WeaponDropper.PickStageTarget): まず屋台を選んでから、その屋台の的をランダムに選ぶ。1つの屋台に同時に出るのは `stageMaxPerStall` (1) 個まで (フィーバー外でメイン屋台だけの時も1個まで。残りは空くのを待ち、stageGiveUp でとばす)。フィーバー中はメイン屋台の選ばれやすさ `stageMainStallWeight` = 0.3 (他は1)。
- **カジノの演出音**: 視界が開けてスロットが見える瞬間の crash / deluxe / cheer を `CasinoHall.revealVolume` (0.45) 倍の音量に。Sfx に `Play(name, volumeScale)` を追加。

### 文字のフォント (WebGL で日本語が消える対策)
- Unity 標準の LegacyRuntime.ttf は英数字のみ。PC/Quest は OS のフォントから日本語を借りるが、WebGL (unityroom) では借りられず日本語が空白になっていた。
- `Assets/Resources/Fonts/MPLUS1p-Medium.ttf` (M PLUS 1p, SIL OFL 1.1) を同梱し、`GalleryBuilder.Prepare()` で `Resources.Load<Font>("Fonts/MPLUS1p-Medium")` を使う (無ければ LegacyRuntime)。
- ライセンス表示は `Resources/THIRD_PARTY_NOTICES.txt` の 3. と末尾の OFL 全文 (ゲーム内のクレジットで読める)。
- フォントを変えたら「シーンに生成」し直すこと (TextMesh はフォント参照をシーンに保存しているため)。
