# Shooting_Gallery_DX
## :fire:ゲーム内容
　このゲームはVRで遊べる**射的ゲーム**です。コントローラーのトリガーを引くだけで遊べて、「2分間」「100,000点」「WorldGate」の三つのモードで遊ぶことができます。一応クリック操作でもプレイすることができます。（WebXRは両目のディスプレイの演算を並列に行えない関係で処理が重く、快適に遊ぶことはできないです。）
- 2MINモード  
   二分間ひたすら的を撃ちまくるモード。点数の的だけではなく、特殊な的も数々登場！。精一杯撃ちきろう！
  
- 100,000Pointsモード   
   100000点取るまで撃ちまくるモード。点数を取り切るまでの時間を競おう！
  
- WorldGateモード  
   14種類の別世界に行く的をかき集めたモード。銃休めにいろいろな世界を巡ろう。（どちらかというと異世界です。）

## :art:制作方法
　普段は設計などを決めてからゲームを作成しているのですが、文化祭までに使える準備時間があまりなかったので、ClaudeCodeを月約3000円で利用し、テストプレイとデバックとAIへの指示出しのみを行って制作いたしました。  
  
　ClaudeCodeはUnityEditor自体を直接操作することができないので、スクリプトによってオブジェクトの生成やマテリアルの生成、EditorのUIの編集などあらゆる操作が行えることを応用し、ほぼすべてコードベースで制作しました。外部アセットやライブラリはAIの指示を元に手動で導入した部分もあります。 
## :rocket:工夫点
　基本的に快適にプレイできるかどうかを追求しました。快適にプレイができるというのは**的を撃ちまくれることを邪魔しない**ということです。
- 的の当たり判定を見た目以上に大きくした。
- あからさまに目線用のガイドを取り付けた。
- 360度見渡してもらうために立体音響や振動によって背後の存在に気づきやすくした。
- 別世界に移行したときには的が車や建物やキャンバスなどになっていてわかりにくいので、色のコントラストで判別しやすくした。

　　ゲームロジックについて、AIにアルゴリズムについて尋ね、必要であれば自分が提案したアルゴリズムなどをプロンプトで読み込ませることで実装しました。曖昧な完成像を指示するだけにはしないように気を付けました。
- 音楽モードでは五線譜を用いるので、音符や休符について1/32拍子が何個分かを整数値としてデータセットを作成し、ランダムに一小節に収めていくアルゴリズムなどを指示した。
- １フレームに複数的が倒れることがあるので、特殊な的などの演出が不用意にかぶらないように一旦スタックに溜め、順番に仕分けるアルゴリズムにかけた。独立して動作できる的と同時だと競合する的があるため調整した。

  文化祭当日では、プレイされない時間帯がないぐらい興味を持ってプレイしていただいたのがとてもうれしかったです。
## :adhesive_bandage:反省点
　文化祭のブースでいろいろな人のプレイを観察し、そこから思ったことについて書きます。半数以上は幼稚園生ぐらいの小さな子供たちに遊んでいただき、同大学の学生や大人の方にも遊んでいただけました。 
- **左手の存在を忘れがちである。**  
   前後左右に屋台が展開されるまで片手しか撃てないようにしている関係で、左手の銃が使えることに気が付かない場合が多くありました。振動を用いたり、視覚的にも工夫をしているのですが、もっと確実に認知させる方法をとるべきだと感じました。

- **上下前後左右をなかなか見ない。**  
   初めの屋台から視線が動かないこともよくありました。おそらく普段VRを使うことはなかなかないので周りを見渡す発想になりづらいからだと考えられます。もっとその常識を壊す誘導をすべきだと思いました。

- **的がわからない。**  
   別世界に飛んだ時に、的を認識するまで時間がかかる場合がありました。「これが的！？」という驚きを狙っている節もあるので、微調整が必要なところだと感じました。  

　ここで痛感したのは自分がデバッカーとして一番機能していない点でした。開発をし続ける中で蓄えられた文脈や知識が邪魔して、初めてプレイする人の感覚というのがわからなくなってしまっていました。それも踏まえて、多くの人に遊んでもらうことの重要性を改めて感じる機会になりました。
