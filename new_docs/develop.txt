 Unknown ステージ 開発メモ
 作成: 2026-10-15 (計画) / 更新: 2026-10-16 (試作を実装 → 立体のまま割れる方式に作り替え)
 ※ 最初の仮の名前は名前の問題で使わない。コード・画面の文字・ファイル名はすべて「Unknown」にした
==========================================================================

■ やりたいこと (ユーザーの希望)
  - 新しい別世界モード「Unknown ステージ」。
  - 的を撃つと、世界がその場で灰色に止まる。写真のような平たい感じではなく、立体感を残したまま割れる。
  - 割れるための破片は、別の部品として用意する。的として働く屋台と見た目は同じにして入れ替える (オブジェクトプールの考え方)。
  - 屋台を部品ごと (提灯・柱…) に分けるのではなく、屋台全部を含めた空間を1つの立体とみなして、ガラスの破片のように切り分けて散らばらせる。
  - 割れた向こうは「ふしぎな空間」(白黒でなくてよい)。ワープゲートが開いて、いろいろな物がこの空間に紛れ込んでくる。
    ゲートの入り口の奥にはそれぞれの世界がずっと続いていて、ワープホールのように見える (アメリカの田舎・宇宙 など)。
  - 浮遊感の強い空間だが、プレイヤーは絶対にその場から動いていない感じ。床の模様は今のまま、床は崩れない。
  - 宙に浮く時計・ドアは気に入っているので、いつも出す。
  - 目玉・渦巻きなど、怖い物は出さない。
  - 帰りは、割れた破片がまた張り合わさって元の世界に戻る。

■ 演出の流れ (実装済み)
  1. ワープゲートの的を撃つ。屋台の的だけしまう (屋台は見えたまま)。
  2. 世界が灰色に止まる (キーン)。本物の屋台などの材質の色だけ灰色にする (GrayWorld。立体のまま)。霧・空の色も灰色に。
  3. 空中に透明なガラスのひびが広がる (ピキピキ)。ガラスはプレイヤーを包む透明な球 (半径 2.4m)。写真は使わない。
     ひびが広がっている間に、屋台・ハッチ・穴のふち・地面をまとめた空間を「1つの立体」として破片に切り分けておく (WorldShatter)。
     - 切り方: ガラスの破片 1枚ごとに、頭からその破片を通って外へ広がる三角の筒を考え、さらに頭からの距離 6m・14m で 手前・中ほど・奥 に切る。
       屋台・提灯・柱・地面の面をこの境目で切って、入っている所ごとに 1つの破片 (メッシュ) にする。提灯や柱も途中から切れる。
       ひびの線と筒の境目が同じなので、見えている景色が、ひびの線どおりに立体のまま割れて見える。
     - 重いので、1フレーム数ミリ秒ずつ少しずつ切る (画面が止まらないように)。間に合わなければ、ひびが入りきったまま待つ。
     - 3D の文字 (看板・点数) は切れないので、真ん中が入っている破片にそのまま乗せる。
     - 切った所から中が見えても穴に見えないように、破片は裏も描く。さらに切り口には同じ灰色のふた (断面) を貼る (ねぎの輪切りのように空洞に見えないように)。
       部品 (まとめたメッシュは頂点の位置でつながっている所ごと) と境目の面ごとに、面の上にできた点の凸包をふたにする。平らな地面は点が一直線に並ぶので、ふたは作らない。
  4. 割れる瞬間に、本物を同じ形・同じ灰色の破片と入れ替える (本物の屋台・ハッチは GameManager.OnUnknownSwapped、地面は UnknownStage が隠す)。
     撃った的の方から、ガラスと空間の破片が立体のまま散らばる (ガシャーン)。回りながら外へ飛び、ゆっくり落ちて、遠くで小さくなって消える。
     - 割れた瞬間から、ガラスの破片は透けずに「灰色に止まった世界の空の色」になる (灰色の景色のまま割れて、抜けた所にだけ ふしぎな空間が見える)。
       描く順番: ふしぎな空間 (2000) → 灰色の空の色の破片 (UnknownShardSolid 2450。ステンシル 128 の印をつける) →
       印の所の奥行きを一番奥に戻す膜 (UnknownShardDepth 2451) → 屋台・地面の立体の破片 (2460)。
       こうすると立体の破片はガラスの前に、ふしぎな空間はガラスの後ろに見える。銃・手はガラスより手前なので印がつかず、そのまま見える。
     - 帰りも、組み上がるまでは灰色の空の色の破片。本物と入れ替える時に、透けるガラスに戻してひびをふさぐ。
       帰り始めにゲートを閉じる (ゲートの膜や名前の文字は半透明で、後から描かれて灰色の破片の上に透けてしまうので)。
     向こうは ふしぎな空間。
  5. ふしぎな空間で遊ぶ (45 秒):
     - 夕暮れのようなラベンダー色の空、パステル色の市松の床 (崩れない)。
     - 宙に浮くドア (少し開いて、すき間から白い光)・時計 (針が逆回り)・柱・行き先のない階段・ゆっくり回る立方体・遠くの大きな球。
     - まわりにワープゲートが 5つ、正面から順にぽんと開く。それぞれの奥の世界:
         COUNTRY (アメリカの田舎: 青空・道・赤い納屋・風車・白い柵・干し草)
         SPACE (星空・輪のある惑星・月)
         BEACH (砂浜・海・ヤシの木・パラソル・太陽)
         CITY (夜の街: 明かりのついたビル・道・月)
         SNOW (雪原・もみの木・雪山・舞う雪・雪だるま)
     - ゲートの奥の世界は 45m 先まで広がる (地面と突き当たりの空。物は、目から入り口を通して見える範囲 = 奥ほど広がる四角い筒の中にだけ置く)。
     - 宙には時計 (200/300)・ドア (100/200) も、ぽんと現れる (的)。
     - ゲートの奥から物が出てきて入り口をくぐり、プレイヤーのまわりまで来てふわふわ漂う。撃つと、別の世界へ転送される (下の「武器」)。
     - 武器: ふしぎな空間に着くと、紫の電撃 (WeaponType.Lightning、"WARP BOLT") になる。押しっぱなしで次々に撃てて、一瞬で届く (まっすぐな太い紫のレーザー 1本。太さは銃の胴より少し細い 2.8cm。Weapons/LightningBolt.cs)。
       当たった物は別の世界へ転送される: 点数はすぐ入り、物の後ろ (プレイヤーから見て奥) に紫のプラズマボール (半透明の外殻と光る芯。芯から外殻へ稲妻の筋) が現れ、
       物の中心からも太い紫のびりびりが出続けて、物 (体と点数の札) とボールが一緒に少しずつ縮んで消える (UnknownObject.Warp)。
       終わる時に、いつもの銃に戻る。
         COUNTRY: 牛 300 / トラクター 200 / 干し草 100
         SPACE: UFO 500 / 人工衛星 300 / 小惑星 100
         BEACH: ビーチボール 100 / 魚 200 / ヨット 300
         CITY: タクシー 200 / バス 300 / 風船 100
         SNOW: 雪だるま 300 / そり 200 / プレゼント 500
  5.5 遊び始めて 15 秒たつと、正面の空に大きなワープホールが開く (プレイヤーの方を向く)。輪の中には、向こうの世界 (雲海の上の星空) が見える。
     ホールはだんだん速くこちらへ迫ってきて、プレイヤーがその輪をくぐる (枠くぐり)。くぐると、背景がそのまま星空に入れ替わっている
     (別の空間に飲み込まれて、風景が続けて変わる感じ。光でごまかしたり、パッと切り替えたりしない)。
     輪は同じ速さのまま後ろへ抜けていき、だんだんゆっくり小さくなって閉じる (振り返ると、遠ざかる輪の中にだけ元の空が見える)。
     ※ 変わるのは背景だけ。床・飾り・ゲート・的は一切変えない (消したり、吸い込んだり、閉じたりしない)。
     - 仕組み: 星空 (内側から見る夜空の球・星・雲海・オーロラ・月) は本物の遠い場所 (85〜90m) に置いてあり、
       Shaders/UnknownCosmos.shader で「目からその点への線が輪の円の中を通るか」を調べて、輪の中に見える所だけ描く。
       くぐった後は逆に「輪の中以外」を描き、輪が閉じたら全部描く。手前の床・飾りは普通に前に描かれる。ステンシルは使わない。
     - 輪は大きい (入り口の半径 14m。42m 先で開く) ので、大きく包み込むようにくぐる。ふちは床・柱・ゲートを通り抜けるが、
       輪も背景の一部として描く (星空 1800 → 輪 1850 → 床や飾り 2000 の順。輪は奥行きを書かない) ので、物はいつも輪の手前に見え、食い込んで見えない。
       モード (_CosmosPortalDir.w): 0 描かない / 1 輪の中だけ / 2 輪の中以外 / 3 全部。UnknownStage.SetPortal で毎フレーム渡す。  6. 帰り: 散らばった破片とガラスが、同じ道を逆にたどって飛んで戻り、灰色の空間が組み上がる (カシャカシャ) →
     ふしぎな空間をしまい、破片を本物の屋台・ハッチ・地面と入れ替える (本物も灰色にして、見た目は同じ。破片はプールへ戻す) →
     ひびが光りながらふさがってガラスが消える → 灰色の世界にゆっくり色が戻る → 屋台の的が出る。

■ 作り (ファイル)
  - Shaders/UnknownShard.shader: 空中のひび割れガラス (ほとんど透明なガラスに、ひびの線)。
  - Modes/Unknown/UnknownStage.cs: 演出の順番・ガラスの球 (実行時に作る1つのメッシュ)・ゲートの開き方・的の出し方・BGM (オルゴール風の明るい曲をコードで合成)。
  - Modes/Unknown/WorldShatter.cs: 空間を破片に切り分ける (三角の筒と距離の面で、面を切る)・破片 (オブジェクトプール)・散らばり方と戻り方。
  - Modes/Unknown/GrayWorld.cs: 物を灰色にする (材質の色・3D の文字・明かりの色)。割れる部品にも同じ灰色の材質を渡す。Set(k) で色をなめらかに戻せる。
  - Modes/Unknown/UnknownObject.cs: ゲートから紛れ込んでくる的 / その場にぽんと現れる時計・ドア (gateIndex = -1)。
  - Modes/Unknown/WonderFloor.cs: ふしぎな空間の床 (タイル。崩れない)。
  - Shaders/UnknownCosmos.shader: 大きなワープホールの向こうの星空 (輪を通して見える所だけ描く)。
  - Core/GameManager.Unknown.cs: CanOfferUnknown / StartUnknown / OnUnknownSwapped / OnUnknownShattered / OnUnknownArrived / EndUnknown / OnUnknownLeft / OnUnknownClosed。
    (ShowHatch に、ふくらむ様子なしですぐ出す instant を足した)
  - Builder/Modes/GalleryBuilder.Unknown.cs: ふしぎな空間 (床・ドア・時計など)・ゲートと奥の世界・紛れ込んでくる物・屋台に出る的の見た目 (UnknownLook)。
  - TargetKind に Unknown / UnknownObject を末尾に追加。WORLD GATE・デバッグモード (背中側の屋台)・WeaponDropper (unknownOffer) にも追加。
  - Sfx: freeze (キーン) / crack (ピキピキ) / shatter (ガシャーン) / reassemble (カシャカシャ) / glass (パリン。今は未使用) / zap (ビリッ。電撃を撃つ) / warpzap (ビリビリ…シュン。転送される)。
  - Shaders/UnknownShardSolid.shader・UnknownShardDepth.shader: 割れた後の、灰色の空の色のガラスの破片と、その所の奥行きを戻す膜。

■ ゲートの奥の世界が「穴の奥に続いて」見える仕組み
  - 奥の世界は、入り口と同じ幅の箱 (床・天井・左右の壁・突き当たり) の中に作る。プレイヤーは入り口の正面 (13m 先) から見るので、
    奥の物ほど小さく見え、箱の外側は入り口の向こうに隠れる。箱の角は、ゲートの太い枠に隠れる。
  - ステンシルなどの特別な描き方は使わない (VR・WebGL で安全)。

■ 軽さ
  - 後処理エフェクトも、360度の撮影 (RenderToCubemap) も使わない (WebGL でもそのまま動く)。
  - 破片の GameObject とメッシュは使い回す。同じ形のメッシュ (立方体など) の頂点は1回だけ読む。飛び終わった破片は描かない。
  - 破片の数: ガラスの破片 約290枚 × 3段 (中身のない所は作らない)。1つの破片は、中に入っている材質の数だけ描く。
  - ガラスは1つのメッシュ (頂点を書き直して動かす)。動かない飾りとゲートは MeshMerger でまとめる (ゲートはゲートごとに)。
  - 灰色の材質の複製は、初めの1回だけ作って使い回す。

■ まだ確かめていないこと (Unity で「シーンに生成」してから)
  - 灰色になる瞬間の引っかかり (初めの1回は材質の複製を作るので少し重い。灰色の光で隠している)。
  - 切り分けが、ひびが広がる間 (約 2.5 秒) に間に合うか (特に Quest)。間に合わなければ、ひびが入りきったまま少し待つ。
  - 割れている数秒間の重さ (描く回数 = 破片の数 × 中の材質の数)。重ければ、ガラスの格子 (rows / cols) か距離の段 (layerCuts) を減らす。
  - 入れ替えた瞬間に、明かり (提灯の光など) の当たり方が変わる。割れる光で隠している。
  - テクスチャを使った物 (ダーツボードなど) は色が残る (このゲームの物はほとんど単色)。

■ これから肉付けする時の候補
  - ゲートの種類を増やす (ジャングル・お菓子の国・海の中 など)。紛れ込んでくる物を増やす。
  - ゲートのまわりのきらきら、ゲートごとの音 (牛の鳴き声・汽笛・波の音 など)。
